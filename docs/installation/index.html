Open a working folder

Choose File > Open Folder in VS Code before Quick Setup. This is where MCP4SAS installs its scripts and where you can save your SAS programs.

Get the SAS files

Download the three encryption JARs from SAS, sign in if requested, and extract them. Java alone does not provide these files.

On a company network?

SAS ODA uses outbound TCP 8591. If blocked, ask IT/IS to allow access to your account's SAS ODA home-region servers. See SAS configuration guidance.

Quick Setup detects Python and SASPy automatically. Local SAS requires an existing licensed installation. Keep account credentials in the private setup terminal. The video already contains the smaller captions; leave external subtitles off.
